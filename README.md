# Alberto Alioto — Portfolio

Sito personale professionale. HTML/CSS puro, nessuna dipendenza.

## Struttura

```
├── index.html              Single-page portfolio (IT/EN)
├── css/style.css           Design system
├── assets/
│   ├── alberto-alioto.png  Foto profilo
│   └── cv-alberto-alioto.pdf  CV (da aggiungere)
└── README.md
```

## Funzionalità

- Toggle lingua Italiano/Inglese
- Responsive (mobile, tablet, desktop)
- Smooth scroll, sticky navbar, animazioni
- SEO optimized (meta tags, OpenGraph)
- Zero dipendenze JavaScript (vanilla)

## Deploy

Hosting: GitHub Pages  
URL: `https://albeali.github.io/portfolio/`

## Modifiche

Modifica `index.html` per aggiornare contenuti.  
Modifica `css/style.css` per lo stile.

Colori principali in `:root` di `style.css`:
- `--navy: #0c1b33` (sfondo scuro)
- `--blue: #1565c0` (accent primario)
- `--accent: #d4a017` (oro)
